<!DOCTYPE html> Document Type Declaration

ประกาศชนิดเอกสาร HTML5

ตำแหน่ง: บรรทัดที่ 1 บนสุดเสมอ

<!DOCTYPE html> ไม่ใช่แท็ก HTML แต่เป็น "คำสั่งบอกเบราว์เซอร์ (Declaration)" ว่าเอกสารนี้เขียนขึ้นตามมาตรฐาน HTML5 เพื่อสั่งให้เบราว์เซอร์เรนเดอร์ใน Standards Mode (โหมดมาตรฐาน)

ผลลัพธ์เมื่อมีแท็กนี้ (With)
  • Standards Mode (HTML5): เบราว์เซอร์ประมวลผลโครงสร้างเอกสารตามมาตรฐาน W3C Standard สากล
  • การจัดวางโครงสร้างแท็ก HTML ทำงานสม่ำเสมอตรงกันในทุกเบราว์เซอร์ (Chrome, Safari, Firefox, Edge)
  • ฟอนต์และองค์ประกอบหน้าเว็บแสดงผลอย่างถูกต้องตามมาตรฐานยุคใหม่
ผลกระทบเมื่อไม่มีแท็กนี้ (Without)
  • ตกสู่ Quirks Mode: เบราว์เซอร์จะจำลองการแสดงผลเหมือนเบราว์เซอร์ยุคเก่า (Legacy Browser)
  • โครงสร้างเพี้ยน: การตีความแท็กต่างๆ จะไม่เป็นไปตามมาตรฐาน HTML5 อาจทำให้หน้าเว็บแสดงผลไม่ตรงกันในแต่ละบราวเซอร์
  • องค์ประกอบ HTML พื้นฐานและฟอนต์แสดงผลกระโดดหรือไม่เท่ากันในแต่ละโปรแกรม
ตัวอย่างการใช้งานที่ถูกต้อง: 
<!DOCTYPE html>
<html lang="th">
  ...
</html>
<html lang="th"> Root Element

รากฐานหลักของโครงสร้างเอกสาร HTML

ตำแหน่ง: ครอบ <head> และ <body> ทั้งหมด

<html> คือ Element สูงสุด (Root Element) ของหน้าเว็บทุกหน้า และการใส่แอตทริบิวต์ lang="th" เป็นสิ่งจำเป็นอย่างยิ่งในการระบุว่าเนื้อหาของหน้านี้เป็น ภาษาไทย

ผลลัพธ์เมื่อมีแท็กนี้ (With)
  • Accessibility สมบูรณ์: เครื่องมืออ่านหน้าจอสำหรับผู้พิการทางสายตา (Screen Readers) สามารถเลือกเสียงอ่านภาษาไทยได้อย่างถูกต้องชัดเจน
  • ระบบแปลภาษาแม่นยำ: Google Chrome / Safari สามารถตรวจจับภาษาเพื่อเสนอการแปลหน้าเว็บได้อย่างถูกต้อง
  • ช่วยให้เบราว์เซอร์และระบบปฏิบัติการจัดการชุดอักขระและหลักการตัดคำภาษาไทยได้อย่างถูกต้อง
ผลกระทบเมื่อไม่มีแท็กนี้ (Without)
  • Screen Reader อ่านเพี้ยน: โปรแกรมช่วยอ่านอาจพยายามอ่านคำภาษาไทยด้วยการสะกดทีละตัวอักษรภาษาอังกฤษ
  • เบราว์เซอร์ Auto-repair: แม้เบราว์เซอร์จะพยายามสร้างโหนด <html> ให้ แต่จะไม่รู้ภาษาต้นทางและทำลายความถูกต้องของโครงสร้าง HTML
  • ระบบค้นหา (SEO) ทำความเข้าใจบริบททางภาษาของหน้าเว็บยากขึ้น
ตัวอย่างการใช้งานที่ถูกต้อง: 
<html>
  <head>...</head>
  <body>...</body>
</html>
<head> Metadata Container

ส่วนหัวเอกสารสำหรับเก็บข้อมูลระบบและ Metadata

ตำแหน่ง: อยู่ก่อนหน้า <body> เสมอ

<head> เป็นคอนเทนเนอร์สำหรับเก็บข้อมูลที่มองไม่เห็นบนตัวหน้าเว็บโดยตรง แต่มีความสำคัญระดับวิกฤตสำหรับระบบและเบราว์เซอร์ เช่น การเข้ารหัสภาษา (Charset), การกำหนดชื่อเรื่องของเว็บ (Title), การตั้งค่าการแสดงผลบนหน้าจอ (Viewport), และข้อมูลกำกับเอกสาร (Metadata)

ผลลัพธ์เมื่อมีแท็กนี้ (With)
  • โครงสร้างถูกต้องตามมาตรฐาน: เบราว์เซอร์รับรู้การตั้งค่าพื้นฐานก่อนจะเริ่มวาดเนื้อหาใน body
  • การจัดการข้อมูลเป็นสัดส่วน: แยกข้อมูลระบบ (Machine data) ออกจากเนื้อหาของผู้ใช้ (User content) ชัดเจน
  • รองรับการใส่แท็กสำคัญ เช่น <title> และ <meta>
ผลกระทบเมื่อไม่มีแท็กนี้ (Without)
  • โครงสร้างเอกสารผิดมาตรฐาน: ไม่มีพื้นที่ที่ถูกต้องสำหรับวางข้อมูลการตั้งค่าและชื่อเรื่อง
  • แท็ก Metadata ปะปนใน body: ทำให้เบราว์เซอร์สับสนในการแยกระหว่างข้อมูลระบบกับเนื้อหาผู้ใช้
  • Web Crawlers และบอทเก็บข้อมูลอาจไม่ประมวลผล Meta tags สำคัญ
ตัวอย่างการใช้งานที่ถูกต้อง: 
<head>
  <meta charset="UTF-8">
  <title>Document</title>
</head>
<title> Document Title

ชื่อของเอกสารหน้าเว็บ (Tab, SEO & Bookmark)

ตำแหน่ง: อยู่ภายใน <head> เท่านั้น

<title> กำหนดหัวข้ออย่างเป็นทางการของหน้าเว็บ ข้อความในแท็กนี้จะ ไม่ปรากฏในพื้นที่เนื้อหาหน้าเว็บ แต่จะถูกส่งต่อไปแสดงบน Browser Tab, หน้าบันทึก Bookmark, และเป็นหัวข้อบรรทัดแรกที่ผู้ใช้เห็นในผลการค้นหาบน Google Search

ผลลัพธ์เมื่อมีแท็กนี้ (With)
  • UX ยอดเยี่ยม: ผู้ใช้ที่เปิดหลายแท็บพร้อมกันสามารถมองเห็นได้ทันทีว่าแท็บนี้คือหน้าอะไร
  • พลัง SEO: Google ให้น้ำหนักของคีย์เวิร์ดในแท็ก <title> สูงมากในการจัดอันดับผลการค้นหา
  • เมื่อบันทึกเป็นบุ๊กมาร์กหรือแชร์ลิงก์ จะได้ชื่อหน้าที่อ่านรู้เรื่องและเป็นมืออาชีพ
ผลกระทบเมื่อไม่มีแท็กนี้ (Without)
  • แท็บแสดงชื่อไฟล์ดิบ: แถบแท็บบราวเซอร์จะแสดงเป็น index.html, IP address หรือ Untitled
  • เสียอันดับ SEO: Google จะพยายามสุ่มหยิบข้อความในหน้าเว็บมาตั้งเป็นชื่อหัวข้อแทน ซึ่งอาจเป็นข้อความเมนูหรือประโยคที่ไม่ตรงประเด็น
  • ผู้ใช้สับสนและหาแท็บของเว็บไซต์ไม่เจอเวลาเปิดทำงานหลายๆ หน้า
ตัวอย่างการใช้งานที่ถูกต้อง: 
<head>
  <title>Document</title>
</head>
<meta charset="UTF-8"> Character Encoding Declaration

การประกาศระบบเข้ารหัสตัวอักษรสากล UTF-8

ตำแหน่ง: บรรทัดแรกๆ ภายใน <head>

<meta charset="UTF-8"> ทำหน้าที่สั่งให้เบราว์เซอร์แปลงรหัสเลขฐานสอง (Bytes) ของไฟล์ให้กลายเป็นตัวอักษรภาษาไทย, สระ, วรรณยุกต์, และ Emoji โดยใช้มาตรฐาน UTF-8 ซึ่งรองรับตัวอักษรของทุกภาษาทั่วโลกกว่า 150,000 ตัว

ผลลัพธ์เมื่อมีแท็กนี้ (With)
  • ภาษาไทยคมชัด 100%: พยัญชนะ สระบน-ล่าง วรรณยุกต์ (เช่น น้ำ, ปู่, กรุงเทพฯ) แสดงผลถูกต้องไม่ตกหล่น
  • รองรับ Emoji และทุกภาษา: แสดงผล 🚀 ✨ 💡 ภาษาจีน ญี่ปุ่น เกาหลี อาหรับ ได้อย่างสมบูรณ์แบบในไฟล์เดียว
  • ป้องกันปัญหาความปลอดภัยประเภท Cross-Site Scripting (XSS) จากการหลอกเปลี่ยน Encoding
ผลกระทบเมื่อไม่มีแท็กนี้ (Without)
  • ภาษาต่างดาว (Mojibake): ภาษาไทยจะกลายเป็นสัญลักษณ์เละๆ เช่น เธชเธงเธฑเธชเธ”เธต หรือ
  • เบราว์เซอร์เดา Encoding เอง: บางเครื่องอาจเดาเป็น Windows-874 (TIS-620) หรือ ISO-8859-1 ทำให้ผลลัพธ์ไม่เหมือนกันในแต่ละผู้ใช้งาน
  • แบบฟอร์ม (Forms) ที่ผู้ใช้พิมพ์ภาษาไทยเข้ามา อาจถูกบันทึกลง Database เป็นข้อมูลเสียหายกู้คืนไม่ได้
ตัวอย่างการใช้งานที่ถูกต้อง: 
<head>
  <meta charset="UTF-8">
  <!-- วางไว้บนสุดของ head ก่อนแท็ก title หรือข้อมูลอื่นๆ เสมอ -->
</head>
