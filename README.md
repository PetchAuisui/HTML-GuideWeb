# HTML Learning Lab

เว็บบทเรียน HTML5 ที่เขียนด้วย React และ Vite ทั้งหน้าแรกและบทเรียนทั้งสามหน่วย

## เริ่มใช้งาน

```sh
npm ci
npm run dev
```

## สร้างไฟล์สำหรับเผยแพร่

```sh
npm run build
npm run preview
```

ไฟล์พร้อมเผยแพร่อยู่ใน `dist/` และเปิดหน้า `index.html`, `lesson1.html`, `lesson2.html`, `lesson3.html` ได้โดยตรง

## โครงสร้าง

- `src/pages/` — เนื้อหาหน้าแรกและบทเรียนในรูปแบบ JSX
- `src/components/` — ส่วนหัว สารบัญ สอนทีละขั้น Simulator ห้องทดลอง และแบบฝึกหัด
- `src/data/` — ข้อมูลขั้นตอนการสอนและคำถาม
- `src/hooks/` — สถานะธีม สารบัญ และความคืบหน้าการอ่าน
- `src/styles/` และ `css/` — รูปแบบหน้าเว็บและ Tailwind ที่สร้างตอน build

React เป็นผู้เรนเดอร์ UI และจัดการสถานะโต้ตอบทั้งหมด ไม่มีการนำ HTML เดิมมาแทรกด้วย `dangerouslySetInnerHTML` หรือรันสคริปต์เก่า หน้า HTML ทั้งสามไฟล์เป็นเพียงจุดเริ่มโหลด React

ห้องทดลองใช้ iframe `srcDoc` ผ่าน React เพื่อแสดง HTML ที่ผู้เรียนเขียน โดยแยกจากหน้าแอปด้วย sandbox และปิดการรัน JavaScript ในตัวอย่าง

โฟลเดอร์ `legacy/` และ `js/` เก็บต้นฉบับเดิมเพื่ออ้างอิงเท่านั้น ไม่ได้ถูก import หรือใช้ใน build ของแอป
